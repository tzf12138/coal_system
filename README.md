# 煤矿智能化充填综合操作平台（创新演示增强版）

本版本在原有“工艺监测、项目管理、设备健康”基础上，进一步增强了培训实训、专家知识库和创新演示模块，重点提升演示可信度与可交互性。

## 运行方式

```bash
pip install -r requirements.txt
python manage.py migrate
python manage.py seed_demo
python manage.py runserver
```

访问地址：`http://127.0.0.1:8000/`

默认账号：

- 用户名：`admin`
- 密码：`admin123456`

## 本次增强内容

### 1. 培训实训管理

- 课程库卡片可点击查看课程详情
- 模拟充填工艺实训场景
- 实训步骤推进与进度条
- 在线测验交互
- 培训记录中增加“查看证书”弹窗

### 2. 专家知识库

- 支持关键词检索
- 支持按知识类别筛选
- 知识条目支持收藏
- 支持引用知识生成处置方案草稿
- 增加故障诊断向导

### 3. 三维仿真与数字孪生展示中心

- 模拟充填站、管路、设备、工作面三维示意场景
- 支持对象点击查看参数
- 支持管路流动、暂停、异常注入
- 支持场景视角切换和实时数据刷新

### 4. AI 与大数据分析中心

- 设备风险评分图表
- 风险表格可点击联动分析结论
- 模型切换：设备健康预测、事故风险预警、生产经营分析
- 特征贡献动态变化

### 5. 一体化智慧管控中心

- 充填站集群模拟图
- 远程集控面板
- 泵站频率、阀组开度、目标料位滑块调节
- 启动自动、手动调节、保存参数、应急停机等演示指令
- 指令与联锁日志

### 6. AR 远程专家指导系统

- 现场第一视角模拟画面
- 设备空间标注点
- 专家会话状态
- 语音指导、截屏留痕、生成工单等交互按钮
- 维修指导清单逐步完成
- 诊断案例和 AR 会话记录展示

## 说明

本系统为演示型平台，未接入真实三维模型、真实 AI 模型、真实 PLC/SCADA 控制接口或真实 AR 眼镜。相关模块以“可演示、可扩展、可替换真实接口”为目标设计。


## 导航结构优化

本版本将原有分散的一级导航整理为：
首页、综合大屏、充填业务、设备诊断、培训知识、创新演示。

其中：
- 充填业务：工艺监测、传感器中心、报警中心、项目管理、任务看板
- 设备诊断：设备健康、远程专家诊断、AR远程指导
- 培训知识：培训实训、知识库
- 创新演示：三维仿真展示、AI分析中心、智慧管控中心
